# Expo SDK 50 to 58 Migration Report

The mobile app now targets Expo SDK 58, React Native 0.88.1, and React 19.3.0.
The following changes were required for the project’s existing features.

| Area | Migration |
|---|---|
| Expo and React Native | Expo modules were aligned to the SDK 58 package manifest; React, React DOM, and React Native were upgraded together. |
| Barcode scanning | Removed `expo-barcode-scanner`; the reusable scanner now uses `CameraView`, `useCameraPermissions`, `barcodeScannerSettings`, and `onBarcodeScanned` from `expo-camera`. |
| Reanimated | Reanimated 4 and `react-native-worklets` replaced Reanimated 3; Babel now uses `react-native-worklets/plugin`. |
| FlashList | Upgraded to v2 and removed the unsupported `estimatedItemSize` prop. |
| Android | Raised `compileSdkVersion` and Build Tools to 37 as required by SDK 58 native modules; kept target API 36. Added package patches to link `c++_shared` in Worklets, Reanimated, Screens, and Expo Modules Core CMake targets. |
| Menus | Removed Zeego and its incompatible native menu dependencies; web and native quick actions now use the existing React Native overlay. |
| React Native types | Replaced `TextInputFocusEventData` with `TextInputFocusEvent`, used `ScrollViewInstance` and `FlashListRef`, and replaced `StyleSheet.absoluteFillObject` with `StyleSheet.absoluteFill`. |
| Expo Router | Updated to the SDK 58 router, kept static web output and disabled asynchronous web routes to preserve the previous behavior, and use the `expo-router/js-tabs` entry point for JavaScript tabs. |
| App config | Moved splash artwork to the `expo-splash-screen` config plugin, disabled camera audio recording, and blocked the unused Android microphone permission. |
| Jest | Updated `jest-expo` and added `@react-native/jest-preset`; React 19 test-renderer mounts and state updates are wrapped in `act`. |
| Node.js | Updated the workspace and EAS build profiles to satisfy SDK 58’s Node.js engine requirements. |

Use `npx expo install --fix` and `npx expo-doctor` when updating SDK-managed
packages. Android native project files must be regenerated or upgraded in sync
with the app config; iOS remains generated by EAS.
